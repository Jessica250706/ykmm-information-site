下面按模块列出 **雪桃资料库** 需要实现的全部接口。  
权限标记：`游客` 无需登录；`用户` 登录用户；`管理员` 管理员；`贡献者` 登录用户且只能操作自己的提交。

---

## 一、认证模块 `/api/auth`

| 方法 | 路径                 | 功能                         | 权限 |
| ---- | -------------------- | ---------------------------- | ---- |
| POST | `/api/auth/register` | 邮箱注册，生成 uid，密码加密 | 游客 |
| POST | `/api/auth/login`    | 登录，返回 token             | 游客 |
| POST | `/api/auth/logout`   | 退出登录                     | 用户 |
| POST | `/api/auth/refresh`  | 刷新 token                   | 用户 |
| GET  | `/api/auth/me`       | 获取当前登录用户信息         | 用户 |
| PUT  | `/api/auth/password` | 修改密码                     | 用户 |

## 六、接口总览

| 模块   | 路径前缀            | 主要权限  |
| ------ | ------------------- | --------- |
| 认证   | `/api/auth`         | 游客/用户 |
| 公共   | `/api/common`       | 游客/用户 |
| 用户端 | `/api/user`         | 游客/用户 |
| 贡献   | `/api/contribution` | 用户      |
| 管理端 | `/api/admin`        | 管理员    |

以上接口覆盖了：

- 用户注册、登录、个人中心；
- 卡面浏览、搜索、详情、图片、系列；
- 剧情分类树、剧情浏览、对话查看；
- 对话喜欢与排行榜；
- 用户提交卡面、剧情、对话；
- 管理员对系统、人物、角色、卡面、剧情、对话、RTV/RC、表情包、贡献审核的全部管理。
